========================================
  GitHub 推送命令
========================================

请在 CMD 或 PowerShell 中执行以下命令：

----------------------------------------
方法 1: 使用 Git Credential Manager（推荐）
----------------------------------------

打开 CMD，执行：
----------------------------------------
cd D:\ec\tengxun
git remote add origin https://github.com/8781742/ffmpeg-kit-plugin.git
git branch -M main
git push -u origin main
----------------------------------------

系统会弹出浏览器让你登录 GitHub 并授权。

----------------------------------------
方法 2: 使用 Personal Access Token
----------------------------------------

如果你没有 GitHub 密码或想使用 Token：

1. 生成 Token:
   - 打开 https://github.com/settings/tokens
   - Generate new token (classic)
   - 勾选 repo 权限
   - Generate
   - 复制生成的 Token

2. 使用 Token 推送:
----------------------------------------
cd D:\ec\tengxun
git remote add origin https://8781742:YOUR_TOKEN@github.com/8781742/ffmpeg-kit-plugin.git
git branch -M main
git push -u origin main
----------------------------------------

注意：把 YOUR_TOKEN 替换成你复制的 Token

========================================
  推送完成后的下一步
========================================

1. 打开 GitHub 仓库页面
   https://github.com/8781742/ffmpeg-kit-plugin

2. 创建 Codespace
   - 点击绿色 Code 按钮
   - 选择 Codespaces 标签
   - 点击 New codespace

3. 等待环境启动（约 2-3 分钟）

4. 在终端执行：
   cd FFmpegKitPlugin_full
   ./gradlew assembleDebug

5. 下载构建产物
   - 文件位置: app/build/outputs/apk/debug/app-debug.apk
   - 重命名为: FFmpegMerge.dex

6. 推送到设备:
   adb push FFmpegMerge.dex /sdcard/ffmpeg_plugin/
